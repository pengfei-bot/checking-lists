1. Qui est responsable

Famlist est éditée par Pengfei DONG (développeur individuel). Contact : dongpf@hotmail.com.

2. À quoi sert Famlist

Famlist aide les familles à gérer des listes de tâches quotidiennes (parent / enfants), avec synchronisation entre appareils, rappels, et éventuellement une photo « preuve » lorsqu’une tâche est terminée.

3. Données que nous traitons

  • Compte parent : identifiants de connexion et informations de profil nécessaires au service.
  • Famille : code famille à court format pour relier les appareils enfants au compte parent.
  • Profils enfants : prénom / nom d’affichage et tâches associées (créées par le parent).
  • Tâches : titres, horaires, récurrence, statut de complétion.
  • Photos de preuve : images que vous choisissez d’ajouter pour une tâche (caméra ou galerie).
  • Notifications / calendrier : rappels locaux ; export éventuel vers le calendrier de l’appareil ou fichier .ics (sur demande de l’utilisateur).
  • Données techniques : journaux techniques limités (ex. diagnostics de crash / fonctionnement) fournis par les plateformes (Apple, Google, Expo) lorsque nécessaire au fonctionnement.

Nous ne vendons pas vos données personnelles.

4. Finalités et bases

  • Fournir et synchroniser le service (exécution du contrat / intérêt légitime à faire fonctionner l’app).
  • Permettre la preuve photo et les rappels (consentement / exécution du service selon le cas).
  • Sécuriser le service et corriger les bugs (intérêt légitime).
  • Répondre aux obligations légales le cas échéant.

5. Enfants

Famlist est conçue pour un usage familial sous la responsabilité d’un parent ou tuteur. Le parent crée le compte et le code famille ; les appareils enfants rejoignent cet espace. Les photos et prénoms d’enfants ne doivent être utilisés qu’avec l’autorisation parentale appropriée. Si vous pensez qu’une donnée a été fournie sans autorisation, contactez-nous pour suppression.

6. Hébergement et sous-traitants

Pour faire fonctionner Famlist, nous utilisons notamment :

  • Supabase : authentification, base de données, synchronisation, stockage des photos.
  • Expo / EAS : distribution et builds de l’application.
  • Apple / Google : App Store, TestFlight, Google Play, notifications et services appareil.
  • GitHub Pages : hébergement éventuel de la démo web et de cette page.

Ces prestataires traitent des données uniquement pour fournir leurs services, selon leurs propres politiques.

7. Conservation

Nous conservons les données tant que le compte / la famille est actif, puis les supprimons ou anonymisons dans un délai raisonnable après demande de suppression ou fermeture du service, sauf obligation légale de conservation.

8. Vos droits (UE / EEE / UK, etc.)

Selon votre lieu de résidence, vous pouvez demander l’accès, la rectification, l’effacement, la limitation, la portabilité, ou vous opposer à certains traitements. Contact : dongpf@hotmail.com. Vous pouvez aussi saisir une autorité de protection des données (en France : CNIL).

9. Sécurité

Nous appliquons des mesures raisonnables (accès restreint, HTTPS, services hébergeurs reconnus). Aucun système n’est parfaitement sécurisé ; évitez de mettre des informations ultra-sensibles dans les titres de tâches ou les photos.

10. Modifications

Nous pouvons mettre à jour cette politique. La date en tête de page sera actualisée. En cas de changement important, nous tenterons d’en informer via l’app ou le site.

Ce document décrit les pratiques de Famlist de façon générale ; il ne constitue pas un conseil juridique.

1. Who is responsible

Famlist is operated by Pengfei DONG (individual developer). Contact: dongpf@hotmail.com.

2. What Famlist does

Famlist helps families manage daily task checklists (parent / children), with sync across devices, reminders, and optional photo “proof” when a task is completed.

3. Data we process

  • Parent account: sign-in credentials and profile data needed for the service.
  • Family: short family code linking child devices to the parent account.
  • Child profiles: display names and related tasks (created by the parent).
  • Tasks: titles, times, recurrence, completion status.
  • Proof photos: images you choose to attach to a task (camera or library).
  • Notifications / calendar: local reminders; optional export to the device calendar or an .ics file (when you request it).
  • Technical data: limited diagnostics provided by platforms (Apple, Google, Expo) as needed to run the app.

We do not sell your personal data.

4. Purposes and bases

  • Provide and sync the service (contract performance / legitimate interest in operating the app).
  • Enable photo proof and reminders (consent / service performance as applicable).
  • Secure the service and fix bugs (legitimate interest).
  • Meet legal obligations when required.

5. Children

Famlist is designed for family use under a parent or guardian. The parent creates the account and family code; child devices join that space. Children’s names and photos should only be used with appropriate parental permission. If data was provided without permission, contact us for deletion.

6. Hosting and processors

To run Famlist we use, among others:

  • Supabase: authentication, database, sync, photo storage.
  • Expo / EAS: app builds and distribution.
  • Apple / Google: App Store, TestFlight, Google Play, device notifications and services.
  • GitHub Pages: optional web demo and this policy page.

These providers process data only to deliver their services, under their own policies.

7. Retention

We keep data while the account/family is active, then delete or anonymize it within a reasonable period after a deletion request or service shutdown, unless law requires longer retention.

8. Your rights

Depending on where you live, you may request access, correction, deletion, restriction, portability, or object to certain processing. Contact: dongpf@hotmail.com. You may also contact a data protection authority (in France: CNIL).

9. Security

We use reasonable measures (restricted access, HTTPS, reputable hosts). No system is perfectly secure; avoid putting highly sensitive information in task titles or photos.

10. Changes

We may update this policy. The date at the top will change. For material updates we will try to notify via the app or site.
